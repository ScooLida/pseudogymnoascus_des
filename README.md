# Detecting Fungal сontamination in museum Specimens, especially genus *Pseudogymnoascus*
##  Work in Progress (WIP)
This pipeline is designed to detect modern fungal contaminants and identify ancient fungal DNA within short-read Illumina sequencing data (FASTQ or compressed FASTQ.GZ formats). It is optimized for screening museum specimens to assess both sample preservation and potential post-mortem contamination.
